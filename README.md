# Vrinda-store-data-analysis-in-excel
Explored Vrinda Store sales data using Excel to understand customer behaviour, sales trends, and top performing categories. Built an interactive dashboard with PivotTables, charts, KPIs, and slicers to turn the data into clear and useful business insights.
📌 Project Overview

This project focuses on analyzing Vrinda Store sales data to better understand customer behaviour, sales trends, and overall business performance.

Using Microsoft Excel, I explored the sales data and created an interactive dashboard to present important insights in a clear and easy-to-understand format. The dashboard helps analyze different aspects of the business, including sales performance, customer demographics, product categories, order status, sales channels, and geographical performance.

The goal of this project was to turn raw sales data into meaningful insights that can help support better and more data-driven business decisions.
